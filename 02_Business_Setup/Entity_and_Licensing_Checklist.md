# Entity & Licensing Checklist

Default assumption: start with the **Data & Software model** (Option 2 in the compliance memo)
since it needs no license to begin building. Update this checklist once you've talked to an
attorney about which model you're running.

## Entity formation (Texas)
- [ ] Choose a final business name; check availability via Texas Secretary of State SOSDirect
      business name search.
- [ ] File a Certificate of Formation (Form 205) for a Texas LLC with the Secretary of State.
- [ ] Get an EIN from the IRS (free, online).
- [ ] Draft an Operating Agreement (single-member or multi-member).
- [ ] Open a business bank account.
- [ ] Register with the Texas Comptroller for a sales-tax permit **if** you end up in the
      finder-fee model (§74.507 path requires one).
- [ ] Get general liability / E&O insurance quotes once the model is locked — errors in a case
      research product carry real liability.

## Licensing (only for Options 1 or 3 in the compliance memo)
- [ ] Texas DPS Private Security Bureau — Class A or Class C Investigations Company license, if
      doing owner-location work beyond straight public-record lookups.
- [ ] If going the attorney-led route: State Bar of Texas licensing for the attorney-owner, and a
      review of how the business entity interacts with law-firm ownership rules
      (non-attorneys generally cannot own equity in a law firm in Texas).

## Immediate no-license groundwork (safe to start now)
- [ ] Public-records research workflow (see 04_Research_System).
- [ ] Case tracker (05_Tracker).
- [ ] Records request to Harris County District Clerk (03_Templates) — requesting the master
      excess-proceeds list is itself a public-information request, not solicitation of a
      claimant, so it doesn't trigger the fee/licensing rules above.
- [ ] Landing page describing the *research service* (06_Website) — kept fee-neutral until the
      model is confirmed with counsel.
