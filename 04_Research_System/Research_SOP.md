# Research SOP — Harris County Excess Proceeds Cases

## Step 1 — Get the master list
Request it from court.registry@hcdistrictclerk.com (template in 03_Templates). Re-request
periodically (e.g., quarterly) since new cases are added after every tax sale.

## Step 2 — Verify each case
For each entry, use the Harris County District Clerk's online "Search Records" tool to confirm:
- The case is still active in the registry (funds not already disbursed)
- Cause number, style, and sale date match
- The 2-year filing deadline (Tax Code §34.04(a)) hasn't passed

## Step 3 — Identify the former owner
Public-record sources only, at this stage (keeps you clear of the DPS investigations-license
question in the compliance memo):
- The underlying foreclosure case file itself (defendant name/address)
- Harris County Appraisal District (HCAD) property records
- Harris County Clerk's real property records (deed history)

If a case needs skip-tracing beyond these public sources to find a current address, flag it and
hold — don't proceed without confirming license requirements with counsel.

## Step 4 — Log it
Add a row to the tracker (05_Tracker/Excess_Proceeds_Case_Tracker.xlsx) with source, verification
date, and confidence level.

## Step 5 — Decide the next action based on the confirmed business model
- Data model: package the verified case + documentation checklist for sale.
- Attorney-led model: hand off to the attorney for direct client engagement.
- Do not contact the former owner yourself until the compliance memo's open questions are
  resolved with an attorney.
